# Gus Portal - Quick Reference

## Stack
React Native 0.76 + Expo 52 + TypeScript + NativeWind + Redux Toolkit + Expo Router

## Domain
Portal

## Structure
- `app/` - Expo Router pages (file-based routing)
- `components/` - Reusable components
- `features/` - Feature modules
- `store/` - Redux store
- `hooks/` - Custom hooks

## Key Points
- Use NativeWind (className) for styling
- Functional components with TypeScript
- Redux Toolkit for state
- File-based routing in app/

## Skills Available
- `rn-test-generator` - Component patterns
- `rn-platform-validation` - Platform validations
- `rn-security` - Security
